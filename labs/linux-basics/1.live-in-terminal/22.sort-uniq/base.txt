
Введение в команды uniq и sort
Команды uniq и sort в Linux часто используются для работы с текстовыми данными, особенно при обработке списков и сортировке строк. Эти команды полезны для упорядочивания данных, удаления дубликатов и анализа текстовой информации.

1. Команда sort
Команда sort используется для сортировки строк в файле или выводе команды. Она может сортировать строки по алфавиту, числовым значениям и другим критериям.

Основные опции sort:

-r — сортировка в обратном порядке (по убыванию).

-n — числовая сортировка.

-u — удаление дубликатов во время сортировки.

Пример:

sort filename.txt
Это выведет строки файла filename.txt в алфавитном порядке.

Для числовой сортировки:

sort -n filename.txt

Сортировка по колонке: -t и -k
-t задаёт разделитель полей (по умолчанию — переход от пробела к непробелу), -k — по какому полю сортировать:
  sort -t: -k3,3n /etc/passwd       — пользователи по UID (3-е поле, числовая сортировка)
  sort -t, -k3,3nr data.csv         — по 3-му полю CSV, по убыванию
-k3,3 означает "только третье поле". Просто -k3 — "с третьего поля и до конца строки", это другой результат.
Ловушка: буквы n, r, h после номера ключа (-k3,3n) — это настройки ключа, и они отменяют общие флаги.
В sort -t, -k3,3n -r флаг -r не подействует, и результат будет по возрастанию. Пишите -k3,3nr.

Другие полезные флаги
  -h — "человеческие" размеры: 500 < 1K < 2M < 3G. Пара du -sh * | sort -h — классика поиска больших каталогов
  -V — версии: v1.2 < v1.9 < v1.10 (обычная сортировка поставила бы v1.10 раньше v1.2)
  -f — без учёта регистра
  -k2,2 -k1,1 — сортировка по второму полю, а при равенстве — по первому
Порядок букв зависит от локали. Для предсказуемого результата в скриптах: LC_ALL=C sort file
2. Команда uniq
Команда uniq удаляет повторяющиеся строки из отсортированного файла или вывода команды. Она работает только с повторяющимися строками, которые идут подряд. Поэтому часто используется вместе с sort.

Основные опции uniq:

-c — подсчёт количества вхождений каждой строки.

-d — выводит только строки, которые повторяются (каждую по одному разу).

-u — выводит только строки, которые встречаются ровно один раз (повторяющиеся выбрасываются целиком).
Не путайте с sort -u: он оставляет по одному экземпляру каждой строки, как sort | uniq.

Пример:

uniq filename.txt
Это удалит подряд идущие дубликаты строк в файле.

Как использовать sort и uniq вместе
Так как uniq удаляет только подряд идущие дубликаты, перед использованием этой команды нужно отсортировать файл с помощью sort.

Пример удаления всех дубликатов:

sort filename.txt | uniq
Если хотите также подсчитать, сколько раз каждая строка встречалась в файле:

sort filename.txt | uniq -c

Топ самых частых строк:
sort filename.txt | uniq -c | sort -rn | head -3
