Команда `ln` в Linux

Команда `ln` используется для создания ссылок на файлы или директории в Linux. Ссылки позволяют обращаться к файлам или каталогам под разными именами или с разных мест в файловой системе. Существует два типа ссылок: жёсткие и символические.

Типы ссылок:
1. Жёсткая ссылка (Hard link): Жёсткая ссылка — это не копия, а ещё одно имя того же файла: обе записи указывают на один и тот же inode
(проверьте: ls -li покажет одинаковый номер inode, а счётчик ссылок станет 2). "Оригинала" у жёсткой ссылки нет — все имена равноправны.
При удалении одного из имён данные сохраняются, пока существует хотя бы одна ссылка на них.
Ограничения: жёсткую ссылку нельзя создать на каталог и на файл в другой файловой системе (ошибка Invalid cross-device link).
2. Символическая ссылка (Symbolic link): Символическая ссылка указывает на путь к другому файлу. Если оригинальный файл удалён, символическая ссылка станет недействительной ("битой").
Важно: относительный путь в символической ссылке отсчитывается от каталога, где лежит сама ссылка, а не от текущего каталога.
ln -s configs/config.txt project/link создаст битую ссылку (она будет искать project/configs/config.txt), правильно:
ln -s ../configs/config.txt project/link
Найти битые ссылки: find . -xtype l

Основные аргументы команды `ln`:

1. `-s` — создание символической ссылки вместо жёсткой. Используется для указания на файл по его пути.
   Пример:
   ln -s /путь/к/файлу ссылка
 
2. `-f` — принудительное создание ссылки, перезаписывая существующий файл или ссылку с тем же именем.
   Пример:
   ln -sf /путь/к/файлу ссылка

3. `-v` — вывод подробной информации о создании ссылки.
   Пример:
   ln -sv /путь/к/файлу ссылка

4. `-i` — запрос подтверждения при перезаписи существующих файлов.
   Пример:
   ln -si /путь/к/файлу ссылка
 
5. `-T` — всегда считает "ссылку" (последний аргумент) именем создаваемой ссылки, даже если по этому имени уже есть каталог;
   без -T ln создал бы новую ссылку внутри этого каталога.
   Пример:
   ln -sT /путь/к/файлу ссылка

6. `-n` — нужен, когда перенаправляют ссылку, которая указывает на каталог.
   Без -n команда ln -sf new_dir dir_link зайдёт по старой ссылке в каталог и создаст ссылку new_dir внутри него,
   а dir_link останется прежней. Правильно:
   ln -sfn new_dir dir_link

Примеры использования:

- Создание жёсткой ссылки:
  ln original.txt hardlink.txt

- Создание символической ссылки:
  ln -s original.txt symlink.txt

- Перезапись существующей ссылки:
  ln -sf original.txt symlink.txt
