Команда tar в Linux
Команда tar (от "tape archive") используется для создания, распаковки и управления архивами в Linux. С помощью tar можно объединить несколько файлов и директорий в один архивный файл (обычно с расширением .tar, .tar.gz, .tgz и т.д.) или распаковать их обратно. tar особенно полезен для создания резервных копий и передачи большого количества файлов.

Основные аргументы команды tar:
-c — создать архив (create).

Используется для создания нового архива.

Пример:
tar -cvf archive.tar /path/to/directory
При абсолютном пути tar сообщит "Removing leading `/' from member names": в архив пути попадут без начального /,
и при распаковке файлы окажутся в текущем каталоге, а не поверх системных.
-x — извлечь архив (extract).

Используется для распаковки архива.

Пример:
tar -xvf archive.tar
При распаковке GNU tar сам определяет тип сжатия: tar -xf archive.tar.gz сработает и без -z.
-f — указать имя архива (file).

Указывает имя архива для создания или распаковки. Этот флаг всегда используется вместе с именем файла архива.
Поэтому в слитных флагах f ставится последней: tar -czvf a.tar.gz dir. Вариант tar -cvfz a.tar.gz dir создаст архив с именем z,
а a.tar.gz tar попытается добавить в архив как файл.

Пример:
tar -cvf my_archive.tar file1 file2
-v — показать подробный вывод (verbose).

Позволяет видеть, какие файлы добавляются или извлекаются. Полезно для отслеживания процесса создания или распаковки архива.

Пример:
tar -cvf archive.tar file1 file2
-z — сжатие с помощью gzip.

Используется для сжатия архива с помощью утилиты gzip, создавая файл с расширением .tar.gz или .tgz.

Пример:
tar -cvzf archive.tar.gz /path/to/directory
-j — сжатие с помощью bzip2.

Сжимает архив с помощью bzip2, создавая файл с расширением .tar.bz2.

Пример:
tar -cvjf archive.tar.bz2 /path/to/directory
-J — сжатие с помощью xz.

Используется для создания архива, сжатого с помощью xz, с расширением .tar.xz.

Пример:
tar -cvJf archive.tar.xz /path/to/directory
-t — просмотр содержимого архива без распаковки.

Полезно для проверки содержимого архива.
Пример:

tar -tvf archive.tar
-C — указание директории для распаковки.

Позволяет указать, в какую директорию распаковать архив. Директория должна существовать — создайте её заранее через mkdir -p.
Пример:

tar -xvf archive.tar -C /path/to/extract

Примеры использования:
Создание архива из директории:

tar -cvf backup.tar /home/user/documents
Создание сжатого архива с gzip:

tar -cvzf backup.tar.gz /home/user/documents
Распаковка архива:

tar -xvf backup.tar
Распаковка сжатого архива .tar.gz в указанную директорию:

tar -xvzf backup.tar.gz -C /home/user/extracted_files
Просмотр содержимого архива:

tar -tvf backup.tar

Часто нужное на практике
Исключить файлы или каталоги:
  tar -czf proj.tgz --exclude='*.log' --exclude=proj/tmp proj
Найти файл в большом архиве и извлечь только его (имя — ровно как в выводе -t):
  tar -tzf proj.tgz | grep main.c
  tar -xzf proj.tgz -C /tmp/restore proj/src/main.c
Отбросить верхний каталог при распаковке: --strip-components=1 (proj/src/main.c распакуется как src/main.c).
Добавить файл в архив: tar -rf archive.tar file — только в несжатый .tar (для .tar.gz: "Cannot update compressed archives").
Сравнить архив с файлами на диске: tar -df archive.tar (код возврата 1, если что-то изменилось).

Права, владельцы и ACL
tar сохраняет права и владельцев в архиве всегда. При распаковке:
  root восстанавливает права и владельцев как в архиве;
  обычный пользователь получает файлы на себя, а права — с учётом своего umask. Флаг -p восстанавливает права как в архиве.
ACL и расширенные атрибуты сохраняются, только если указать --acls (и --xattrs) и при создании, и при распаковке:
  tar --acls --xattrs -cpf etc.tar /etc
  tar --acls --xattrs -xpf etc.tar -C /restore

Сжатие отдельных файлов (без tar)
  gzip file        — заменит file на file.gz;  gzip -k file — оставит оригинал
  gunzip file.gz   — распаковать (то же: gzip -d);  gzip -l file.gz — степень сжатия
  zcat / zless / zgrep file.gz — читать без распаковки (так удобно смотреть старые логи /var/log/*.gz)
  bzip2 / bunzip2 / bzcat и xz / unxz / xzcat — то же для .bz2 и .xz
Обычно xz сжимает сильнее и медленнее, gzip — быстрее и слабее, bzip2 — посередине.
