Команда chmod
chmod используется для изменения прав доступа к файлам и директориям. 
В Linux существует три типа прав доступа: чтение (read, r), запись (write, w) и выполнение (execute, x). Эти права могут применяться к трем категориям пользователей:
  владелец (user, u),
  группа (group, g),
  другие пользователи (others, o).

Синтаксис:
chmod [опции] права файл

Основные параметры команды chmod:
Изменение прав с использованием символьного представления:

u — права владельца (user),
g — права группы (group),
o — права других пользователей (others),
a — права всех категорий пользователей (all).
Вы можете добавлять или убирать права с помощью знаков + и -.

Пример:
Добавление прав на выполнение для всех:
  chmod a+x file.txt

Изменение прав с использованием числового представления (октального):

4 — чтение (read),
2 — запись (write),
1 — выполнение (execute).
Права для каждой категории — сумма этих чисел (7 = 4+2+1, 6 = 4+2, 5 = 4+1). Например, число 755 означает:

7 (чтение, запись, выполнение) для владельца,
5 (чтение, выполнение) для группы,
5 (чтение, выполнение) для других.

Пример:
chmod 755 file.txt

Рекурсивное изменение прав для всех файлов в директории: Параметр -R позволяет рекурсивно изменить права для всех файлов в директории.
Осторожно: -R применяет одни и те же права и к файлам, и к каталогам. Для каталога право x означает "можно войти и обращаться к файлам внутри",
поэтому chmod -R 644 /path/to/directory отнимет x у всех подкаталогов — в них нельзя будет зайти, а сам chmod споткнётся
на полпути с ошибкой Permission denied.
Правильно задавать права файлам и каталогам по-разному. Заглавная X ставит x только каталогам (и файлам, у которых x уже был):
chmod -R u=rwX,go=rX /path/to/directory
Или явно, через find:
find /path/to/directory -type d -exec chmod 755 {} +
find /path/to/directory -type f -exec chmod 644 {} +

Примеры использования chmod для стандартных путей Debian (файлы в /etc, /var, /usr принадлежат root — для них команды выполняются через sudo):
Добавить права на выполнение для владельца файла /home/user/script.sh:
chmod u+x /home/user/script.sh

Установить права на чтение и запись для владельца и группы, а для других только чтение для файла /etc/myconfig.conf:
chmod 664 /etc/myconfig.conf

Удалить права на запись для других пользователей для файла /var/log/syslog (в Debian 12+ этого файла по умолчанию нет — журнал ведёт journald):
chmod o-w /var/log/syslog

Установить права на чтение и выполнение для всех пользователей для файла /usr/local/bin/app:
chmod a+rx /usr/local/bin/app

Рекурсивно дать всем право читать содержимое /var/www (каталоги 755, файлы 644):
chmod -R u=rwX,go=rX /var/www
Вариант chmod -R 755 /var/www сделал бы исполняемыми все файлы, включая html и картинки, — так делать не нужно.
