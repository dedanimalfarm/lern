Подготовка (нужен sudo; удобнее всего на учебной VM):
  sudo groupadd dev
  sudo useradd -m -s /bin/bash -G dev alice
  sudo useradd -m -s /bin/bash -G dev bob
  sudo useradd -m -s /bin/bash carol
  sudo apt install -y acl        — если getfacl не найден

1. Выведите свой umask. Какие права получат новый файл и новый каталог? Проверьте, создав их.
2. Установите в текущей оболочке umask 027, создайте файл и каталог и проверьте права через stat -c "%a %n".
3. Найдите в /usr/bin все файлы с битом SUID. Почему у passwd он нужен?
4. Создайте каталог /srv/share с группой dev: участники dev читают и пишут, остальные не имеют доступа,
   а новые файлы автоматически получают группу dev. Проверьте: создайте файл от имени alice
   (sudo -u alice touch /srv/share/a.txt) и посмотрите его группу.
5. Создайте каталог /srv/drop, куда все могут класть файлы, но удалять — только свои.
   Проверьте: bob не может удалить файл alice.
6. Создайте /srv/share/report.txt и дайте пользователю carol (он не в группе dev) право только на чтение
   этого файла через ACL. Проверьте: sudo -u carol cat /srv/share/report.txt
   Не получилось? Посмотрите права на каталог /srv/share (namei -l /srv/share/report.txt) и дайте carol
   минимально необходимое право на каталог.
