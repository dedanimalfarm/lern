Все ответы ищите только в man, --help, help и /usr/share/doc — без интернета.

1. Найдите в man ls флаг, который сортирует файлы по размеру (сначала большие).
2. Найдите через --help флаг grep, который выводит только имена файлов с совпадениями.
3. man cd не находит страницу. Почему? Получите справку по cd другим способом.
4. С помощью man -k узнайте, какой командой меняют срок действия пароля пользователя.
5. Чем отличаются man crontab и man 5 crontab? Найдите в man 5 crontab, что означает запись */5 в поле минут.
6. Найдите в man find раздел EXAMPLES и выпишите пример безопасного удаления файлов через find -print0 | xargs -0.
