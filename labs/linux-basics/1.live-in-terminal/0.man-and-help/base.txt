Справка без интернета: man, --help, help, apropos, /usr/share/doc

Зачем это нужно
На экзамене LFCS из документации доступны только man-страницы и документы,
установленные дистрибутивом (/usr/share/doc и подкаталоги). Интернета нет.
Кто быстро находит нужный флаг в man, тот не тратит время на угадывание.
Эта ЛР — нулевая: навык пригодится во всех остальных.

1. Краткая справка: --help
Почти все программы GNU печатают короткую справку по флагу --help:
  ls --help
  tar --help | head -n 15
У tar в начале --help есть готовые примеры (раздел Examples).
Если справка длинная, листайте её через less: grep --help | less

2. Встроенные команды bash: help
cd, echo, export, history, type, read — встроенные команды оболочки (проверьте: type cd).
Отдельной man-страницы у них нет: man cd ответит "No manual entry for cd".
Для них есть help:
  help cd
  help export
  help          — список всех встроенных команд

3. Полная документация: man
  man ls
man открывает страницу в less, поэтому работают те же клавиши:
  /текст   — поиск вниз, n / N — следующее / предыдущее совпадение
  g / G    — в начало / в конец, q — выход
Как читать страницу:
  NAME        — что делает команда, одной строкой
  SYNOPSIS    — синтаксис: в [квадратных скобках] необязательное, ... — можно повторить.
                Например, у tar: tar -x [-f ARCHIVE] [OPTIONS] [MEMBER...] — после имени
                архива можно перечислить отдельные файлы, и распакуются только они.
  DESCRIPTION / OPTIONS — описание и флаги
  EXAMPLES    — готовые примеры (есть не везде: у find и sudoers есть, у tar нет)
  SEE ALSO    — связанные страницы
Быстро перейти к примерам: внутри man наберите /EXAMPLES и Enter.

4. Разделы man
Одно и то же имя может быть и командой, и файлом настроек. Страницы разложены по разделам:
  1 — команды пользователя         (man 1 crontab — команда crontab)
  5 — форматы файлов настроек       (man 5 crontab — формат строк в crontab-файле)
  7 — обзоры и соглашения           (man 7 signal — список сигналов)
  8 — команды администратора        (man 8 useradd)
Без номера man открывает первый найденный раздел: man crontab — это раздел 1.
Номер раздела пишут в скобках: crontab(5) означает "man 5 crontab".

5. Поиск, когда не знаете имени команды: man -k (apropos)
man -k ищет слово в однострочных описаниях (NAME) всех страниц:
  man -k "space usage"      — найдёт df и du
  apropos password          — то же самое, apropos = man -k
  man -k "^crontab$"        — точное имя: покажет оба раздела, 1 и 5
  apropos -s 8 user         — искать только в разделе 8
whatis имя (то же, что man -f) показывает описание одной строкой для всех разделов:
  whatis passwd
Если man -k на всё отвечает "nothing appropriate", индекс страниц не построен:
  sudo mandb

6. /usr/share/doc
В /usr/share/doc/<пакет>/ лежат README, журнал изменений и часто готовые примеры конфигов:
  ls /usr/share/doc/sudo/examples/       — в том числе образец файла sudoers
Сжатые файлы (*.gz) читаются без распаковки: zless или zcat.
  zless /usr/share/doc/sudo/NEWS.gz

7. Где man нет
В docker-образах Ubuntu man-страницы вырезаны (образ "minimized"), и man ответит сообщением
"This system has been minimized". Вернуть их: sudo unminimize (в Ubuntu 24.04 сначала
sudo apt install unminimize). На обычном сервере и на экзамене man-страницы есть.

Порядок действий, когда не помните флаг:
  1) команда --help | grep -i слово       — быстрее всего
  2) man команда, затем /слово              — если в --help нет
  3) man -k слово                           — если не помните саму команду
  4) /usr/share/doc/<пакет>/                — если нужен пример конфига
