1. По SYNOPSIS в man tar выясните, как извлечь из архива только один файл. Проверьте на практике:
   создайте архив из двух файлов и извлеките один из них в пустой каталог.
2. С помощью apropos найдите команды, которые показывают: свободное место на файловых системах;
   размер каталогов; список блочных устройств.
3. Найдите на диске образец файла sudoers, который поставляется с пакетом sudo. В каком каталоге он лежит?
4. Какой сигнал по умолчанию отправляет kill? Найдите ответ в man 1 kill и сверьте номер сигнала в man 7 signal.
5. Выпишите номера разделов man, в которых есть страница passwd, и объясните, что описано в каждом.
6. Засеките время: за 3 минуты найдите в man, как заставить tail следить за файлом по имени,
   даже если его переименовали при ротации логов.
