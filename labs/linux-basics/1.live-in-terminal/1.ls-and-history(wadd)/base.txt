Этот набор лабораторных работ предназначен для тех, кто хочет глубже понять и освоить основы работы с Linux. 
Независимо от того, являетесь ли вы студентом, разработчиком, системным администратором или просто интересующимся пользователем,
эти лабораторные работы помогут вам получить практические навыки и уверенность в использовании Linux.

Работа будет выстроена следующим образом:
- в каждой ЛР будет находиться файл base.txt с основной информацией(про утилиту, команду или что угодно), его мы открываем и читаем первым делом.
- есть файл exercises.txt содержит упражнения и задания для практики
- homework.txt так же файл с заданиями для закрепления материала
Исключение — эта ЛР: упражнения лежат в подкаталоге group-symbols/ (exercises.txt и подсказки hints.txt), а homework.txt здесь нет.
Вместо него — сертификация по ls в подкаталоге ls-certification/ (см. конец файла).

Имя каталога этой ЛР содержит скобки, а для bash это спецсимволы. Без кавычек
  cd 1.ls-and-history(wadd)
завершится ошибкой "syntax error near unexpected token `('". Берите имя в кавычки или дополняйте по Tab:
  cd '1.ls-and-history(wadd)'

В первой лабораторной работе нам предстоит познакомиться с основными видами файлов и директорий в OS Linux.


Регулярные файлы (Regular Files):
    Описание: Обычные файлы, содержащие данные, текст, исполняемые файлы и т.д.
    Пример: Текстовый файл, изображение, исполняемый файл.

Каталоги (Directories):
    Описание: Файлы, которые содержат список других файлов и директорий.
    Пример: /home, /etc.


Чтобы увидеть регулярные файлы и директории нам хватит команды: ls 

В операционной системе Linux скрытые файлы и директории — это те, имена которых начинаются с точки (.). 
Такие файлы и директории обычно используются для хранения конфигурационных файлов, временных данных и других ресурсов, 
которые не должны быть видны пользователю по умолчанию.

По умолчанию команда ls не отображает скрытые файлы. Чтобы увидеть скрытые файлы, нужно использовать флаг -a (all):
  ls -a
ls -a показывает ещё и две служебные записи: . (текущий каталог) и .. (родительский).
Чтобы увидеть скрытые файлы без них, используйте -A (almost all):
  ls -A

Тип файла показывает первый символ в выводе ls -l:
  -  обычный файл
  d  каталог
  l  символическая ссылка
  c  символьное устройство (например, /dev/null)
  b  блочное устройство (диск, например /dev/sda или /dev/vda)
  p  именованный канал (FIFO)
  s  сокет
Пример (флаг -d — показать сам каталог, а не его содержимое):
  ls -ld / /bin /dev/null /etc/passwd
В Ubuntu 22.04+ и Debian 12+ /bin — символическая ссылка на usr/bin, поэтому у неё тип l.


История команд (history)
bash запоминает введённые команды. В интерактивной оболочке при выходе они сохраняются в файл ~/.bash_history.
  history           — показать историю с номерами
  history 5         — последние 5 команд
  !42               — повторить команду с номером 42
  !!                — повторить последнюю команду (например: sudo !!)
  !$                — последний аргумент предыдущей команды
  Ctrl+R            — поиск по истории (повторное Ctrl+R — следующее совпадение)
  history -c        — очистить историю в памяти текущей сессии. Файл ~/.bash_history при этом
                      не очищается: старые команды в нём остаются, а при выходе bash допишет туда новые
  history -w        — записать историю текущей сессии в ~/.bash_history (перезаписав файл)
  history -c && history -w — очистить и память, и файл
Размер истории задают переменные HISTSIZE (в памяти) и HISTFILESIZE (в файле).



Сертификация «Lord of the LiSts»
Когда освоите ls, проверьте себя: 26 коротких задач, одна задача — одна команда, проверяет скрипт.
За все 26 — звание Lord of the LiSts и сертификат. Начните с ls-certification/README.md:
  cd ls-certification && ./setup.sh
Шпаргалка — ls-certification/card.txt: каждая её команда — одна задача.
