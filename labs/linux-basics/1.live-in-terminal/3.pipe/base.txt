Объяснение пайпа (|) и команд ls и wc
Пайп (|) — это оператор в командной строке Unix/Linux, который позволяет передавать вывод одной команды в качестве ввода для другой команды. Это мощный способ комбинирования команд для последовательной обработки данных.
Через пайп идёт только стандартный вывод (stdout). Сообщения об ошибках (stderr) проходят мимо пайпа прямо на экран:
в ls /etc /nonexistent | wc -l ошибка про /nonexistent будет видна, но в подсчёт не попадёт.

Команда ls: Используется для отображения списка файлов и директорий.
Пример:
ls
Этот пример выводит список всех файлов и директорий в текущей директории.

Опция -l для ls: Используется для отображения списка файлов в длинном формате, который включает подробную информацию о файлах, такую как права доступа, количество ссылок, владелец, группа, размер, дата модификации и имя файла. Пример:
ls -l
Этот пример выводит список всех файлов и директорий с подробной информацией о каждом файле.
Первая строка вывода ls -l — "total N" (сколько места занимают файлы, в блоках по 1 КБ). Это не файл,
поэтому ls -l | wc -l покажет на единицу больше, чем файлов в каталоге.

Команда wc: Используется для подсчета строк, слов и байтов в файлах или в потоке данных.
Пример использования с флагами:

wc -l: подсчитывает количество строк.
wc -w: подсчитывает количество слов.
wc -c: подсчитывает количество байтов (для кириллицы в UTF-8 это не то же самое, что символы — их считает wc -m).
Пример использования комбинации команд ls, wc и пайпа (|):
Подсчитайте количество файлов в директории:

ls | wc -l
В этом примере команда ls выводит список всех файлов и директорий, а wc -l подсчитывает количество строк в этом списке, что соответствует количеству файлов и директорий.
Почему это работает: в терминале ls раскладывает имена по колонкам, но когда вывод уходит в пайп, ls печатает каждое имя на отдельной строке.
Скрытые файлы (имена с точкой в начале) ls без флагов не показывает, поэтому они в подсчёт не попадают.
