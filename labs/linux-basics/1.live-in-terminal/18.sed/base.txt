sed — правка текста без редактора

sed (stream editor) читает текст построчно, применяет к каждой строке команды и печатает результат.
Главное применение у администратора — менять строки в конфигах одной командой: быстро,
без ошибок при наборе и одинаково на десяти серверах. В этой ЛР есть учебный конфиг
sshd_config.sample — все примеры ниже выполняйте на нём.

1. Замена: s/что/на что/
  sed 's/yes/no/' sshd_config.sample
Заменяет ПЕРВОЕ вхождение в каждой строке. Чтобы заменить все вхождения в строке, добавьте флаг g:
  echo "aa aa" | sed 's/aa/bb/'     — bb aa
  echo "aa aa" | sed 's/aa/bb/g'    — bb bb
Флаг i — без учёта регистра: s/yes/no/gi
Если в шаблоне есть /, возьмите другой разделитель — любой символ после s:
  echo /usr/local/bin | sed 's|/usr/local|/opt|'
& в замене — найденный текст целиком: echo port=8080 | sed 's/[0-9]\+/[&]/'   — port=[8080]

2. По умолчанию sed ничего не меняет в файле
Результат печатается на экран, файл остаётся прежним. Это удобно: сначала посмотреть, потом применить.
Изменить сам файл — флаг -i (in-place):
  sed -i 's/^X11Forwarding yes/X11Forwarding no/' sshd_config.sample
С резервной копией (рядом появится sshd_config.sample.bak):
  sed -i.bak 's/^X11Forwarding yes/X11Forwarding no/' sshd_config.sample
Правило: сначала запустите команду без -i и сравните с оригиналом, потом добавляйте -i:
  sed 's/^#\?Port .*/Port 2222/' sshd_config.sample | diff sshd_config.sample -

3. Адреса: к каким строкам применять команду
  sed '7s/yes/no/' file              — только к 7-й строке
  sed '/^Permit/s/yes/no/' file      — только к строкам, подходящим под шаблон
  sed '5,10s/yes/no/' file           — к строкам с 5-й по 10-ю
  sed '/^Pubkey/,/^Password/p' file  — диапазон: от строки с шаблоном 1 до строки с шаблоном 2
  $ — последняя строка

4. Печать нужных строк: -n и p
-n отключает печать всех строк, p печатает выбранные — получается grep с адресами:
  sed -n '/^Pass/p' sshd_config.sample
  sed -n '7,8p' sshd_config.sample   — строки 7–8
  sed -n '/PermitRootLogin/=' file   — номер строки с совпадением

5. Удаление, вставка, замена строки целиком
  sed '/^#/d' file                   — удалить строки-комментарии
  sed -e '/^#/d' -e '/^$/d' file     — и пустые строки: остаются только действующие настройки
  sed '2i новая строка' file         — вставить перед 2-й строкой
  sed '/^PermitRootLogin/a # проверено' file   — добавить после найденной строки
  sed '$a последняя строка' file     — добавить в конец файла
  sed '/^PermitRootLogin/c PermitRootLogin no' file   — заменить найденную строку целиком
Несколько команд: через -e или через точку с запятой: sed 's/yes/YES/; s/no/NO/' file

6. Типичные правки конфигов
Раскомментировать параметр и задать значение (строка могла быть как "#Port 22", так и "Port 22"):
  sed -i 's/^#\?Port .*/Port 2222/' sshd_config.sample
  \? — "предыдущий символ может быть, а может не быть" (здесь — символ #)
Закомментировать строку:
  sed -i 's/^PasswordAuthentication/#&/' sshd_config.sample
Поменять значение, не трогая ключ:
  sed -i 's/^\(PermitRootLogin\) .*/\1 no/' sshd_config.sample
  \( \) — группа, \1 — то, что в неё попало. С флагом -E скобки пишутся без обратной косой черты:
  echo "John Smith" | sed -E 's/(\w+) (\w+)/\2, \1/'   — Smith, John

7. Ловушки
- sed -i без проверки — частая причина сломанного конфига. Смотрите результат без -i или делайте -i.bak.
- . в шаблоне — любой символ. Чтобы найти точку, пишите \. (например, s/192\.168/10.0/).
- В BSD/macOS sed -i требует аргумент: sed -i '' 's/a/b/' file. В Linux (GNU sed) — как в этой ЛР.
- После правки конфига службы проверьте его синтаксис, если у службы есть такая проверка
  (sshd -t, nginx -t, visudo -c), и только потом перезапускайте службу.
