1. Создайте файл hello.txt и запишите в него строку "Hello, World!" с использованием команды echo и оператора >.

2. Добавьте строку "How are you today?" в файл hello.txt с использованием команды echo и оператора >>.

3. Создайте файл info.txt и запишите в него строку "This is some information."

4. Добавьте строку "Additional information here." в файл info.txt.

5. Используйте команду echo для записи строки "This is the beginning of the log." в файл log.txt.

6. Выполните ls /etc/hostname /nonexistent так, чтобы результат попал в ok.txt, а ошибка — в err.txt.

7. Выполните ту же команду так, чтобы и результат, и ошибка попали в один файл all.txt. Сделайте это двумя способами.

8. Выполните ls /etc/hostname /nonexistent 2>&1 > wrong.txt. Где оказалась ошибка и почему?

9. Найдите все файлы с именем passwd во всей системе так, чтобы на экране не было ни одного сообщения "Permission denied".
