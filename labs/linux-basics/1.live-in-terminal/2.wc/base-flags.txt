wc - word count (количество слов)

-l: Подсчитывает количество строк.
Пример использования:
wc -l file.txt
Выводит количество строк в файле file.txt.
Точнее, wc -l считает символы перевода строки (\n). Если у последней строки файла нет \n в конце, она не попадёт в счёт.

-w: Подсчитывает количество слов.
Пример использования:
wc -w file.txt
Выводит количество слов в файле file.txt.
Словом считается любая последовательность символов без пробелов, табуляций и переводов строки: "1." и "—" тоже считаются словами.

-c: Подсчитывает количество байтов.
wc -c file.txt
Выводит количество байтов в файле file.txt. Байты и символы совпадают только для латиницы (ASCII):
в кодировке UTF-8 одна кириллическая буква занимает 2 байта, поэтому для file.txt wc -c покажет заметно больше, чем wc -m.

-m: Подсчитывает количество символов.
wc -m file.txt
Выводит количество символов в файле file.txt. Это полезно для подсчета символов в файлах с многобайтовыми символами, где количество байтов может не соответствовать количеству символов.

-L: Показывает длину самой длинной строки.
wc -L file.txt
Выводит длину самой длинной строки в файле file.txt. Длина считается в экранных колонках:
обычный символ — одна колонка, а табуляция растягивается до ближайшей позиции, кратной 8 (printf "a\tb\n" | wc -L выведет 9).

Примеры комбинирования флагов и указания нескольких файлов:
Вы можете использовать несколько флагов одновременно для получения разных типов информации сразу. Например:
wc -l -w -c file.txt
Этот пример выведет количество строк, слов и байтов для файла file.txt.

wc -l -w -c homework.txt additional.txt
Этот пример выведет количество строк, слов и байтов для файлов homework.txt и additional.txt.
Если файлов несколько, последней строкой wc выводит сумму — строку total.

Порядок колонок не зависит от порядка флагов: всегда строки, слова, символы, байты, длина строки.
wc -c -l file.txt и wc -l -c file.txt выведут одно и то же.

Если подать файл через перенаправление ввода, wc не знает имени файла и выводит только число — так удобнее в скриптах:
wc -l < file.txt

По итогу:
wc -l — количество строк
wc -w — количество слов
wc -c — количество байтов
wc -m — количество символов
wc -L — длина самой длинной строки
