# Пробный экзамен: задачи

18 задач, 100 баллов, порог — 67, время — 2 часа. Все задачи выполняются от root (`sudo -i`).
Из документации пользуйтесь только `man`, `--help`, `help` и `/usr/share/doc`.
Ответы-файлы кладите в `/opt/exam/answers/`. Задача засчитывается, только если выполнены все её условия.
Номер в скобках — тема из `1.live-in-terminal`, где разбирается нужный навык.

Задачи 13, 14, 17 и 18 опираются на пользователя и группу из задачи 12 — сделайте её раньше.

---

**1. (3 балла) Справка** *(тема 0)*
Не пользуясь интернетом, найдите команду, которая меняет срок действия пароля и учётной записи пользователя.
Запишите только её имя в `/opt/exam/answers/01.txt`.

**2. (5 баллов) Поиск в журнале** *(темы 2, 3, 4)*
В журнале `/opt/exam/logs/app.log` уровень сообщения указан в квадратных скобках.
- Запишите в `/opt/exam/answers/02.txt` одно число — количество строк уровня `ERROR`.
- Сохраните в `/opt/exam/answers/02-disk.txt` все строки уровня `ERROR`, в которых встречается слово `disk` в любом регистре. Порядок строк — как в журнале.

**3. (5 баллов) Перенаправление** *(тема 5)*
Запустите `/opt/exam/bin/report.sh` так, чтобы его стандартный вывод попал в `/opt/exam/answers/03.out`, а сообщения об ошибках — в `/opt/exam/answers/03.err`.

**4. (6 баллов) Поиск файлов** *(тема 12)*
Найдите в `/opt/exam/data` и его подкаталогах все обычные файлы, которые принадлежат пользователю `webuser` и больше 1 МиБ (1048576 байт).
Запишите их полные пути, по одному на строку, в `/opt/exam/answers/04.txt`.

**5. (6 баллов) Резервная копия конфигов** *(темы 8, 12)*
Скопируйте все файлы с окончанием `.conf` из `/opt/exam/etc` (включая подкаталоги) в `/opt/exam/backup/etc`, сохранив структуру подкаталогов:
например, `/opt/exam/etc/db/db.conf` должен оказаться в `/opt/exam/backup/etc/db/db.conf`.
Других файлов в `/opt/exam/backup/etc` быть не должно.

**6. (6 баллов) Перенос старых файлов** *(темы 8, 12)*
Переместите в каталог `/opt/exam/archive/old` все файлы из `/opt/exam/tmp`, которые изменялись больше 7 суток назад.
Остальные файлы должны остаться в `/opt/exam/tmp`. Время изменения файлов сохранить.

**7. (7 баллов) Правка конфига** *(тема 18)*
В файле `/opt/exam/config/app.conf`:
- раскомментируйте параметр `max_connections` и задайте ему значение `200`;
- измените значение `debug` с `true` на `false`.
Комментарий в последней строке и остальные строки не меняйте.

**8. (6 баллов) Отчёт по сотрудникам** *(темы 19, 20, 22)*
В `/opt/exam/data/employees.csv` поля разделены запятой: имя, отдел, зарплата; первая строка — заголовок.
Запишите в `/opt/exam/answers/08.txt` трёх сотрудников отдела `IT` с самыми большими зарплатами — по строке на человека
в формате `имя зарплата` (через пробел), по убыванию зарплаты. Учтите только отдел, который называется ровно `IT`.

**9. (5 баллов) Активные клиенты** *(темы 20, 22)*
В `/opt/exam/logs/access.log` первое поле каждой строки — IP-адрес клиента.
Запишите в `/opt/exam/answers/09.txt` пять IP-адресов с наибольшим числом запросов в формате `количество IP`, по убыванию количества
(именно так выводит `uniq -c`).

**10. (6 баллов) Архив проекта** *(тема 26)*
Создайте архив `/opt/exam/backup/project.tar.gz` (tar + gzip) каталога `/opt/exam/project` без подкаталога `logs` и без файлов `*.tmp`.
Пути внутри архива должны начинаться с `project/`.

**11. (5 баллов) Восстановление из архива** *(тема 26)*
Из архива `/opt/exam/archive/site.tar.xz` извлеките только файл `site/conf/nginx.conf` в каталог `/opt/exam/restore`
(результат: `/opt/exam/restore/site/conf/nginx.conf`). Другие файлы из архива не извлекайте.

**12. (7 баллов) Пользователь и группа** *(тема 14)*
Создайте группу `devops` с GID `2050` и пользователя `deploy`:
домашний каталог `/home/deploy` (должен быть создан), оболочка `/bin/bash`, дополнительная группа `devops`,
учётная запись действует до `2030-12-31` включительно.

**13. (6 баллов) Ограниченный sudo** *(тема 14)*
Разрешите пользователю `deploy` выполнять от root без пароля команду `/usr/bin/journalctl` — и только её.
Конфигурация sudo после изменения должна проходить проверку `visudo -c`.

**14. (5 баллов) Общий каталог** *(тема 11)*
Создайте каталог `/srv/devops`: владелец `root`, группа `devops`. Владелец и участники группы могут читать, писать и входить в каталог,
остальные не имеют никакого доступа. Новые файлы в каталоге должны автоматически получать группу `devops`.

**15. (7 баллов) Доступ к отчёту** *(тема 11)*
Пользователь `auditor` должен иметь возможность читать файл `/opt/exam/secure/report.txt`, но не изменять его.
Права (`chmod`) и владельцев файла и каталога `/opt/exam/secure` не меняйте. Пользователь `guest` по-прежнему не должен читать файл.

**16. (5 баллов) Ссылки** *(тема 26)*
- Ссылка `/opt/exam/current` сейчас указывает на `/opt/exam/releases/v1`. Перенаправьте её на `/opt/exam/releases/v2`.
- Создайте жёсткую ссылку `/opt/exam/data/docs/hard.txt` на файл `/opt/exam/data/docs/master.txt`.

**17. (5 баллов) Окружение** *(тема 6)*
- У всех пользователей при входе в систему должна быть переменная окружения `EXAM_ENV` со значением `lfcs`.
- У пользователя `deploy` при входе должна быть переменная `APP_HOME=/opt/app`, у остальных пользователей её быть не должно.

**18. (5 баллов) umask** *(тема 11)*
Сделайте так, чтобы при входе пользователя `deploy` его umask был `0027`. У других пользователей umask меняться не должен.
