# DevSecOps 2026

Готовые учебные материалы курса DevSecOps в формате Markdown (`.md`).

## Подход к обучению

Материалы строятся вокруг проверяемых инженерных задач:
угроза → требование → реализация → проверка → доказательство.

Теория, примеры и лабораторные генерируются на основе официальной документации,
стандартов, манифестов с подтверждённым авторством и авторитетных исследований.
Перед публикацией проверяются источники, применимость версий и корректность примеров.

## Оформление материалов

- Один самостоятельный материал — один файл `.md`.
- Имена файлов: `NN-topic.md`, например `01-threat-modeling.md`.
- В начале материала указываются цель, необходимые знания, статус и дата проверки.
- Для технических примеров фиксируются версии инструментов и окружения.
- Утверждения сопровождаются ссылками на конкретные разделы первоисточников.
- Лабораторные содержат ожидаемый результат, критерии зачёта и порядок очистки стенда.
- Непроверенные команды и допущения явно отмечаются; они не выдаются за проверенные результаты.
- Пароли, действующие токены и другие секреты в материалы не включаются.
